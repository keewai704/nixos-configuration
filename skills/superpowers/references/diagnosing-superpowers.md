# Diagnosing Superpowers

Diagnose the specified session without silently changing skills or exporting data.

Identify the symptom and session. Prefer relevant context already available and
bounded history tools. If the session cannot be identified, ask for its locator
instead of searching every conversation.

Locate the request, advertised description, loaded instructions, applicable
higher-priority policy, tool actions, and result. Cite message IDs or file/line
coordinates. Distinguish stale discovery or deployment, an ambiguous trigger,
conflicting instructions, tool/runtime failure, and a decision that did not follow
the available instruction.

Separate observations from hypotheses. Recommend the smallest correction and
a scenario that can verify it. Keep diagnosis-only requests read-only; repair
only when authorized.

This adaptation has no transcript-export or issue-filing helper. Private session
data and logs are not automatically safe to upload, even after scrubbing.
An authorized export needs explicit content review, and publication needs its
own authority.
