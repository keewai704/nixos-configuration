# Executing Plans

Apply the [Pi/Astra working agreement](../using-superpowers/SKILL.md).

Review the plan against the current checkout, request, and repository rules.
Resolve genuine gaps before the affected step; do independent authorized work
while blocked. Update stale details from evidence rather than blindly following
old file paths or assumptions.

Execute cohesive tasks in dependency order. Track completed work and evidence,
use [test-driven-development](../test-driven-development/SKILL.md) for relevant
behavior changes, and run the checks each change requires. Delegate useful
bounded work according to the active policy; inline execution is not an opt-out
from required delegation or independent review.

Give progress updates at meaningful milestones. Do not stop after an arbitrary
batch for renewed permission when implementation is already authorized.
Investigate unexpected failures using
[systematic-debugging](../systematic-debugging/SKILL.md).

After integration, obtain the required independent assessment using
[requesting-code-review](../requesting-code-review/SKILL.md), address findings,
and use [verification-before-completion](../verification-before-completion/SKILL.md).
Complete repository-required commits and activation; report blockers separately
from finished implementation. Do not hand back a plan with unchecked tasks as
though the requested work were complete.
